# VovedeShell

Эмулятор командной оболочки UNIX-подобной операционной системы,
реализованный на Python.

Проект выполняется в рамках учебного задания по дисциплине "Конфигурационное управление".

## Требования

- Python 3.12+
- pytest

## Запуск

### Windows

Для запуска через командную строку:

```text
run.bat
