# VovedeShell

Эмулятор командной оболочки UNIX-подобной операционной системы,
реализованный на Python.

Проект выполнен в рамках учебного задания по дисциплине
«Конфигурационное управление».

## Возможности

Проект поддерживает:

* интерактивный режим работы командной оболочки;
* выполнение стартовых скриптов;
* загрузку виртуальной файловой системы из JSON-файла;
* работу с виртуальной файловой системой в памяти;
* инициализацию VFS стандартной структурой;
* просмотр содержимого каталогов с помощью `ls`;
* переход между каталогами с помощью `cd`;
* получение имени пользователя с помощью `whoami`;
* отображение времени работы оболочки с помощью `uptime`;
* копирование файлов внутри VFS с помощью `cp`;
* обработку ошибок команд и VFS;
* автоматическое тестирование с помощью `pytest`.

## Требования

* Python 3.12 или выше
* pytest 9.x

## Запуск

### Запуск оболочки

Для запуска проекта выполните из корневой директории:

```text
.\run.bat
```

По умолчанию загружается виртуальная файловая система
из файла `data\vfs.json`.

### Запуск с указанием VFS

```text
.\run.bat --vfs data\vfs.json
```

Оболочка загружает виртуальную файловую систему из указанного
JSON-файла.

### Запуск стартового скрипта

```text
.\run.bat --script scripts\start.txt
```

Оболочка последовательно выполняет команды из указанного
стартового скрипта.

### Запуск с VFS и стартовым скриптом

```text
.\run.bat --vfs data\vfs.json --script scripts\start.txt
```

Сначала загружается VFS из JSON-файла, после чего выполняется
стартовый скрипт.

### Справка

```text
.\run.bat --help
```

Выводит список доступных параметров запуска.

## Поддерживаемые команды

### `ls`

Выводит содержимое текущего каталога или указанного каталога.

```text
ls
ls /home
```

### `cd`

Изменяет текущий каталог.

```text
cd /home
cd ..
cd .
```

### `whoami`

Выводит имя текущего пользователя.

```text
whoami
```

### `uptime`

Показывает время работы текущего экземпляра оболочки.

```text
uptime
```

### `cp`

Копирует файл внутри виртуальной файловой системы.

```text
cp /home/user.txt /home/copy.txt
cp user.txt copy.txt
```

Команда поддерживает абсолютные и относительные пути.

### `vfs-init`

Создаёт стандартную виртуальную файловую систему.

```text
vfs-init
```

После выполнения создаётся структура:

```text
/
├── home/
└── readme.txt
```

### `exit`

Завершает работу оболочки.

```text
exit
```

## Виртуальная файловая система

VFS хранится в оперативной памяти и представлена в виде дерева
каталогов и файлов.

Пример структуры:

```text
/
├── home/
│   └── user.txt
└── readme.txt
```

Данные VFS могут быть загружены из JSON-файла.

Операции `ls`, `cd` и `cp` работают с виртуальной файловой системой,
не изменяя файлы и каталоги операционной системы.

## Стартовые скрипты

Стартовый скрипт содержит последовательность команд оболочки.

Пример:

```text
ls
cd /home
ls
whoami
uptime
```

Пустые строки и строки, начинающиеся с `#`, игнорируются.

При запуске скрипта команды выполняются последовательно, а их
результаты и сообщения об ошибках выводятся в консоль.

## Тестирование

Для запуска всех автоматических тестов выполните:

```text
python -m pytest
```

Для подробного вывода:

```text
python -m pytest -v
```

Тесты проверяют:

* работу парсера команд;
* запуск и выполнение команд оболочки;
* конфигурацию;
* стартовые скрипты;
* загрузку и валидацию VFS;
* работу `ls`;
* работу `cd`;
* работу `whoami`;
* работу `uptime`;
* работу `cp`;
* обработку ошибок;
* работу `vfs-init`.
